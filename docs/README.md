# Documents

Specs, plans, post-mortems, acceptance records and research for cairn, newest first. Each
line gives the decision the document led to, including rejected proposals, negative
results and plans that were superseded. A document records what was true on its date;
the code and CHANGELOG.md say what is true now. Versions for the 2026-10-30 rows are those
of the stacked pull requests that added them.

Add a row when you add a file under `docs/`: the date the document states for its
research or observation (else its first commit), a link, its kind and one decision line.
`tests/test_test_discipline.py` fails when a file is missing, a link is broken or the
dates are out of order.
